"# Vue Pizza

Интернет-магазин пиццы — пет-проект для портфолио с конструктором пиццы, корзиной и оформлением заказа.

## О проекте
Одностраничное приложение на Vue 3 с каталогом пицц, выбором размера и типа теста, сортировкой и фильтрацией по категориям, корзиной и оформлением заказа.

## Функционал
- Каталог пицц с фильтрацией по категориям
- Сортировка товаров
- Выбор размера и типа теста для каждой пиццы
- Корзина с расчётом итоговой цены заказа
- Сохранение корзины в localStorage (данные не пропадают при перезагрузке страницы)
- Оформление заказа
- Переиспользуемые UI-компоненты
- Плавные анимации интерфейса (AutoAnimate)
- Адаптивная вёрстка

## Архитектура
- Composition API с переиспользуемыми хуками (composables) для логики корзины, цен, категорий и заказов
- Provide/Inject для передачи данных между компонентами без проброса пропсов
- Модульная структура UI-компонентов (папка UI)

## Стек
- Vue 3 (Composition API)
- Vue Router
- Tailwind CSS
- AutoAnimate (анимации появления/удаления элементов)
- LocalStorage (сохранение состояния корзины)
- JavaScript, HTML5, CSS3
